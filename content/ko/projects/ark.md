## 문제

고객마다 문서 관리, OCR, RAG, 위키, 개발용 VM 등 필요한 기능이 달라 사내망용 AI 장비의 구성을 각각 맞춰야 했습니다. 이미지를 수작업으로 만들면 필요한 기능이나 의존성, 버전을 일관되게 관리하기 어려웠습니다.

## 만든 것

Jetson 장비용 OS 이미지를 기능별로 조립하고, 설치 후 웹에서 실제 사용할 기능을 선택할 수 있는 시스템을 만들었습니다. 공통 기반 위에 문서 관리, 검색, 위키, 외부 AI 연결, VPN, 개발 작업공간 등을 조합합니다. 첫 설정에서는 새로 설치하거나 기존 데이터를 사용하고, 조건이 맞는 백업을 복원할 수 있습니다.

## 설계에서 고민한 것

- **기능 조합과 의존성 관리.** 보드·프로파일·모듈을 선언적으로 정의하고 필수 의존성을 함께 포함합니다. 필요한 빌드 자산이 없거나 검증에 실패하면 선택한 기능을 조용히 빼지 않고 중단합니다.
- **기본 접속과 부가 기능 분리.** VPN이나 인증서 설정이 실패해도 사내망의 기본 웹 접속과 구분해 상태를 확인할 수 있도록 설계했습니다.
- **기존 데이터 보호.** 첫 설정에서 NVMe의 식별 정보와 데이터 배치를 확인하고 자동으로 포맷하지 않도록 했습니다. 백업 복원도 장비와 이미지의 호환성을 확인한 뒤 진행합니다.
- **설치 방식 선택.** 온라인 첫 설정은 고정된 자산을 내려받고, 사전 탑재 방식은 필요한 자산을 이미지에 넣어 설치할 수 있도록 구성했습니다.

## 현재 상태

실제 장비에서 이미지 설치와 첫 설정 웹 접근을 확인했습니다. 기능별 동작과 인수 테스트는 추가 확인이 필요합니다.
